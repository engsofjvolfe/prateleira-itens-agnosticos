Regras para todo código, seja qual formato for:
- Sempre sem nada hardcoded.
- Sempre DRY.
- Sempre modular.
- Sempre future proof.
- JSON têm apenas dados, nunca narração.
- Testes, se existirem, nunca devem ser overfit.
- Código nunca se escreve por comando de terminal, só pelas ferramentas de escrever arquivo.
